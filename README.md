O projeto combina uma interface moderna e responsiva com uma apresentação voltada para engenharia de software, IA e prototipação de produtos digitais.

## 🧠 Inteligência Artificial

O projeto possui uma seção dedicada ao estudo e aplicação de **Sistemas Cognitivos e Modelos Preditivos**.

As principais áreas apresentadas são:

### 🤖 Chatbots com Python

Desenvolvimento de assistentes inteligentes utilizando modelos Llama 3 através da infraestrutura Groq e modelos da OpenAI, com interfaces reativas desenvolvidas em Streamlit.

**Tecnologias:**

* Groq LPUs
* OpenAI SDK
* Streamlit

### 📄 Automação de Documentos

Pipelines voltados para extração, síntese e geração de documentos estruturados utilizando modelos de IA.

Inclui:

* Structured Outputs
* Function Calling
* JSON Schema
* Geração de documentos
* Exportação programática

### 🎯 Engenharia de Prompt

Aplicação de técnicas para criação e otimização de prompts, incluindo:

* System prompts
* Few-shot conditioning
* Restrições comportamentais
* Guardrails
* Avaliação de respostas
* Padronização de saídas

### 📊 Machine Learning & GenAI

Experimentação com modelos supervisionados e não supervisionados, tratamento de dados e ajuste de parâmetros relacionados à geração de respostas.

### 🔎 RAG — Retrieval-Augmented Generation

Implementação conceitual de arquiteturas RAG para combinar modelos de linguagem com dados externos.

Fluxo apresentado:

```text
Query
  ↓
Embeddings
  ↓
Vector Store
  ↓
Contextual LLM
```

O objetivo é permitir respostas mais contextualizadas utilizando informações externas sem a necessidade de retreinamento do modelo.

---

## 🧩 Estratégias de Prompt

O portfólio apresenta três estratégias principais de contextualização:

| Estratégia | Exemplos | Objetivo                                                 |
| ---------- | -------: | -------------------------------------------------------- |
| Zero-Shot  |        0 | Executar uma tarefa sem exemplos                         |
| One-Shot   |        1 | Fornecer um exemplo de referência                        |
| Few-Shot   |       2+ | Utilizar múltiplos exemplos para aumentar a consistência |

A proposta apresentada é demonstrar como exemplos de entrada e saída podem ser utilizados para orientar modelos de linguagem e melhorar a consistência das respostas.

## 🎨 Prototipação

A metodologia apresentada utiliza o **Google Stitch** como ferramenta de prototipação e ideação.

O processo de desenvolvimento é estruturado em quatro etapas:

```text
01 → Ideia
      ↓
02 → Protótipo (Stitch)
      ↓
03 → Desenvolvimento
      ↓
04 → Solução
```

O objetivo é acelerar a transformação de conceitos e requisitos em interfaces validadas e posteriormente em código funcional.
